Setting it up

Clarity is designed to be set up by a family member on a spare iPhone or iPad, then left running by the bed or in the kitchen. It takes about a minute.

  1. Open the app. You will see the clock straight away — there is no account to create.
  2. Tap "Set up" — small grey text in the bottom-right corner of the clock. It is deliberately easy to miss, so the person using the app doesn't wander into settings.
  3. Add your message and reminders, and the button to call you.
  4. Leave the device plugged in. The screen stays on, so it is always there.

Adding the button to call you

  1. Tap Set up, then scroll to "A button to call you".
  2. Enter your name in the first box and your phone number in the second.
  3. Choose FaceTime, FaceTime audio or Phone call.
  4. Test it before you leave. The button only appears on the clock once you have set it up, so on a fresh install there is nothing there yet.

Once set, a large "Call Sarah" button sits at the very top of the clock — one tap and it dials.

Common questions

My reminders never rang. Versions before 1.0.2 only understood times typed exactly as 9:00. Anything else — 9am, 9.30, 930 — was saved without a time, so it never rang, and there was no warning that it hadn't worked. Update to the latest version: it understands all of those, and repairs any reminder that was affected. It is worth opening Set up afterwards to check each reminder shows the time you expected.

The call button isn't on the clock. It stays hidden until it is set up, so it is never a dead button. Tap Set up, scroll to "A button to call you", and add a name and number.

The alarm keeps going / doesn't go. When a reminder is due, Clarity rings, then rests and tries again a few times rather than sounding all day. Once your loved one taps "I've done it", it stops and a calm done stays on screen so they can see it is dealt with.

They tapped "I've done it" by mistake. Tap it once more and the reminder goes straight back.

The screen keeps turning off. Clarity asks iOS to keep the screen awake while it is open. If the device still sleeps, check Settings → Display & Brightness → Auto-Lock is set to Never, and keep it on charge.

Does it need internet? No. The clock, your message and the reminders all work with no connection at all.

Is it really free? Yes — no ads, no subscription, no in-app purchases, and no plan to add any.

Your privacy

Clarity has no accounts, no servers and no analytics. Your reminders, your message and the phone number you enter stay on the device. Full details in the privacy policy.

A note for families

Clarity does not diagnose or treat any condition. It is a supportive day-orientation clock and a gentle reminder — it is not a substitute for a carer's help with medication, and it should not be relied on as the only prompt for anything that matters medically.
